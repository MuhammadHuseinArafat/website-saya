# Website Portofolio Pelajar

Contoh website statis lengkap (HTML, CSS, JavaScript) untuk latihan
memublikasikan website dengan GitHub Pages.

## Isi repository

- `index.html` : struktur halaman (beranda, tentang, keterampilan, proyek, kontak)
- `style.css`  : tampilan, responsif, dan mode gelap
- `script.js`  : interaksi (menu ponsel, mode gelap, filter proyek, validasi formulir)
- `README.md`  : penjelasan proyek (file ini)

## Fitur

- Menu navigasi yang berubah menjadi tombol pada layar ponsel
- Mode gelap/terang (pilihan tersimpan di browser)
- Teks mengetik bergantian dan angka statistik yang naik
- Bar keterampilan yang terisi saat terlihat
- Filter proyek berdasarkan kategori
- Formulir kontak dengan validasi sederhana (tidak mengirim data)
- Tombol kembali ke atas

## Cara melihat di komputer

Simpan keempat file di satu folder yang sama, lalu buka `index.html`
dengan browser.

## Cara memublikasikan

1. Unggah semua file ke repository GitHub (di level paling atas, bukan di subfolder).
2. Buka Settings > Pages.
3. Pada Build and deployment, pilih Deploy from a branch.
4. Pilih branch `main` dan folder `/ (root)`, lalu klik Save.

Alamat website biasanya berbentuk
`https://USERNAME.github.io/NAMA-REPOSITORY/`
(ganti USERNAME dan NAMA-REPOSITORY dengan milik Anda).

## Yang perlu Anda ganti

- `[Nama Kamu]`, `[Nama Sekolah]`, `[Kelas]` di `index.html`
- Angka keterampilan dan statistik (hanya contoh)
- Daftar proyek

Jangan menuliskan data pribadi sensitif di website yang dipublikasikan.
